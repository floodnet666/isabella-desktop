# Diretório de Áudio e Visemas em Runtime

Este diretório é reservado para buffers de áudio gravados temporariamente pelo microfone (VAD), fatias de streaming fonético (PCM 24 kHz) e amostras de validação sonora.

Arquivos de áudio voláteis (`*.wav`, `*.mp3`) são ignorados pelo Git para manter o repositório enxuto.
