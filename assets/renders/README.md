# Renders e Validações Visuais — Isabella Desktop

Este diretório contém as evidências de auditoria e validação visual de renderização 3D Gaussian Splatting (3DGS).

## Pastas de Documentação

- `test_emotions/`: Renders de validação das 8 expressões emocionais FACS do modelo (`F1` a `F8`), demonstrando a deformação dérmica contínua $C^1$ e rotação cervical 3D sem quebra de geometria.
- `test_expressions/`: Renders de validação dos ciclos biológicos (sorriso, piscar de olhos e visemas labiais).

Renders temporários de desenvolvimento (como snapshots e varreduras multiview) são ignorados pelo controle de versão.
